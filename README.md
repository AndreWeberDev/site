# Portfólio - André Junior

Este é o portfólio pessoal do André Junior, desenvolvedor em formação.

## 🚀 Como usar

### Para GitHub Pages (Recomendado)
1. Faça upload dos arquivos da pasta `public` para o seu repositório GitHub
2. Ative o GitHub Pages nas configurações do repositório
3. Seu site estará disponível em: `https://seu-usuario.github.io/nome-do-repositorio`

### Para desenvolvimento local
1. Navegue até a pasta `server`
2. Instale as dependências: `npm install`
3. Inicie o servidor: `npm start`
4. Acesse: `http://localhost:5487`
